# IGSave

IGSave 是一款本地优先的 iOS 媒体保存工具。它接收 Instagram 帖子、Reel、当前可访问的快拍或媒体直链，在用户有权访问内容的前提下，将图片和视频保存到系统照片图库。

## 核心能力

- 从 App、系统分享扩展、URL Scheme 和快捷指令接收链接。
- 支持预览选择、轮播素材、批量队列、取消、重试和部分成功恢复。
- 使用系统后台下载；App 暂时离开前台或重新启动后可以继续未完成任务。
- 保存历史、搜索与筛选、重复保存提醒、专用 IGSave 相册和账号收藏。
- 提供本机脱敏诊断、缓存管理和明确的错误恢复建议。

## 隐私边界

- 不包含广告或第三方统计 SDK。
- Instagram 登录会话保留在本机 WebKit 数据存储中。
- 完整链接、Cookie、用户名和本机文件路径不会写入诊断报告。
- 诊断记录不会自动上传；只有用户主动导出后才会离开设备。
- 不绕过登录、私密账号、内容权限、DRM 或平台访问控制。

## 开发与验证

- Xcode 26 或更新版本。
- iOS 26.0 或更新版本。
- 主 App 和分享扩展需要同一个 App Group：`group.com.haru.ig-save`。
- 提交前应完成自动化测试、Debug/Release 构建、真机分享保存流程，以及 `RELEASE_CHECKLIST.md` 中的发布检查。
